# Saudi Used Cars Price Prediction

Predicting used car prices in Saudi Arabia using **machine learning**. The project explores the dataset, preprocesses features, and trains regression models like **XGBoost** and **CatBoost** to estimate fair car prices.

## Tech Stack
- Python, Jupyter Notebook
- Pandas, NumPy
- Scikit-learn, XGBoost, CatBoost

## Features
- Data exploration & preprocessing
- Regression model training
- Price prediction and evaluation
